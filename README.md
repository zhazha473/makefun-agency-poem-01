# agency-poem-01

A short poem about agency: the power to choose and to act, and what passes
between a person and their AI agent when a task is handed over.

`main.ts` (Node 22, standard library only) writes the poem to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
